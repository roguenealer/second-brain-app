Privacy policy

Second Brain · last updated 2026-10-16

Who uses it

Second Brain is a private, personal tool. Its only user is its owner, the person behind the GitHub account roguenealer. It does not collect data from anyone else.

Google data it accesses

  • Gmail: reads the owner's messages, and sends a message only when the owner has approved that specific message.
  • Google Calendar: reads the owner's events.
  • Google Drive: reads the owner's files, and creates and updates its own backup files in the owner's Drive.

How the data is used

Only to keep the owner's private notes up to date (people, projects, plans and deadlines) and to write the owner's daily briefing. The data is processed on the owner's own computer, and by the owner's AI assistant (Claude, by Anthropic) acting for the owner.

Where it is stored

Notes are stored as files on the owner's computer, with backups in the owner's own Google Drive. Sign-in credentials are stored encrypted on the owner's computer.

Sharing

Google user data is never sold, never used for advertising, and never shared with anyone other than the services named above that work for the owner.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Through the owner's GitHub profile: github.com/roguenealer.
